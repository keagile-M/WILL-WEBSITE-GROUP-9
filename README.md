# Pawsitive Pet Academy Website

This website is made with HTML, CSS and JavaScript.

## Files
- HTML files make up the website pages.
- `style.css` controls the layout, colours and appearance.
- `script.js` handles the menu, form checks and fee calculator.
- The `images` folder contains the pictures and academy logo.

## Website features
- Home, courses, about, contact, fees and enrolment pages.
- A menu that works on desktop and mobile.
- A fee calculator that updates when courses are selected.
- Automatic discounts:
  - 1 course: no discount
  - 2 courses: 5% discount
  - 3 courses: 10% discount
  - More than 3 courses: 15% discount
- Basic form checks on the contact and enrolment forms.

Open `index.html` in a browser to view the website.
